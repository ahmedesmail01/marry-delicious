The text wordmark uses **Playball**, self-hosted from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/playball). It is a close visual match to the supplied raster logo; the exact original typeface cannot be determined from the menu alone. The SIL Open Font License is retained at `public/fonts/Playball-LICENSE.txt`.

Original menu images and extracted illustrations were supplied by the project owner.

The main Arabic/Latin interface font is **Cairo**, self-hosted from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/cairo). Its variable weight range is 200–1000; the SIL Open Font License is at `public/fonts/Cairo-LICENSE.txt`. Selected for its bilingual consistency and suitability for readable menu typography. See [Google Design’s overview of modern Arabic typography](https://design.google/library/modernizing-arabic-typography-type-design).
